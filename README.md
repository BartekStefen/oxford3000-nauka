# Słówka 3000 – angielski PL→EN

Darmowa aplikacja webowa (PWA) do nauki 3805 słówek z listy Oxford 3000 (A1–B2):
fiszki z obracaniem i przesuwaniem, tryb Nauka (wybór → wpisywanie), Pisanie z poprawą błędów,
Testy, powtórki trudnych słówek, statystyki, wymowa (brytyjski głos syntetyczny), tryb offline.

Statyczna strona – wystarczy dowolny hosting plików (np. GitHub Pages). Postępy zapisują się w przeglądarce (localStorage).
